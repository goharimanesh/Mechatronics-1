معادله کنترلر PID

ترکیب سه عمل کنترل

معادله در حوزه زمان

u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·(de/dt)
  • P (تناسبی): پاسخ فوری به خطای فعلی
  • I (انتگرالی): حذف خطای تجمعی
  • D (مشتق): پیش‌بینی و کاهش نوسان

مشخصات پاسخ پله

معیارهای ارزیابی عملکرد کنترلر

Rise Time (t_r)

زمان رسیدن از ۱۰٪ به ۹۰٪ مقدار نهایی

Settling Time (t_s)

زمان ورود به باند ±۵٪ و ماندن در آن

Overshoot (M_p)

حداکثر فراتر رفتن از مقدار هدف

Steady-State Error

خطای باقیمانده در حالت پایدار

مقایسه P، PI و PID

تکامل عملکرد کنترلر

  • P تنها: سریع اما با خطای ماندگار
  • PI: حذف خطا اما با Overshoot بیشتر
  • PID: پاسخ سریع، بدون خطا، با Overshoot کم

گسسته‌سازی PID

از معادله پیوسته به کد دیجیتال

معادله گسسته

u[k] = Kp·e[k] + Ki·Σe[j]·Δt + Kd·(e[k]-e[k-1])/Δt

Δt: زمان نمونه‌برداری — هرچه کوچکتر، دقت بالاتر

الگوریتم محاسبات PID

فلوچارت اجرا در هر چرخه

کد شبه

error = setpoint - input;
integral += error * dt;
derivative = (error - prevError) / dt;
output = Kp*error + Ki*integral + Kd*derivative;
prevError = error;

معماری سخت‌افزاری پروژه

Arduino + L298N + Motor + Encoder

اجزای اصلی

  • Arduino UNO: مغز کنترلر
  • L298N: درایور موتور
  • DC Motor: عملگر
  • Encoder: سنسور بازخورد

دیاگرام کنترل سرعت موتور

حلقه بازخورد کامل

نحوه کار

Setpoint (RPM هدف) → مقایسه با RPM اندازه‌گیری‌شده → محاسبه خطا → PID → PWM به درایور → موتور می‌چرخد → انکودر RPM را برمی‌گرداند.

تنظیم دستی PID

روش تجربی — گام به گام

۴ مرحله اصلی

  • مرحله ۱: فقط P — افزایش تا نوسان
  • مرحله ۲: کاهش P به نصف
  • مرحله ۳: افزودن I برای حذف خطا
  • مرحله ۴: افزودن D برای کاهش Overshoot

فلوچارت تنظیم PID

مسیر رسیدن به پارامترهای بهینه

نکته کلیدی: تنظیم PID یک فرآیند تکراری است. با تغییر هر پارامتر، رفتار سیستم را مشاهده کنید و دوباره تنظیم کنید.

استفاده از کتابخانه PID_v1

ساده‌ترین راه پیاده‌سازی در آردینو

کد کامل

#include <PID_v1.h>

double Setpoint, Input, Output;
double Kp=2, Ki=0.5, Kd=0.1;
PID myPID(&Input, &Output, &Setpoint, Kp, Ki, Kd, DIRECT);

void setup() {
    Input = analogRead(A0);
    Setpoint = 100;
    myPID.SetMode(AUTOMATIC);
}

void loop() {
    Input = analogRead(A0);
    myPID.Compute();
    analogWrite(3, Output);
}

جلسه بیست‌ودوم - پیاده‌سازی PID

الف) سوالات مفهومی

۱ تفاوت رفتار P، PI و PID را در پاسخ پله توضیح دهید.
۲ چرا گسسته‌سازی PID ضروری است؟
۳ پدیده Wind-up چیست و چگونه از آن جلوگیری می‌کنیم؟

ب) تمرین‌های عملی

۴ کتابخانه PID_v1 را نصب کنید و یک کنترلر ساده برای LED بنویسید.
۵ برای یک موتور DC با انکودر، سیستم کنترل سرعت با PID طراحی کنید.
۶ پارامترهای PID را با روش دستی (Ziegler-Nichols) تنظیم کنید.

ج) تمرین نوشتاری

۷ فلوچارت الگوریتم PID را رسم کنید.
۸ جدول اثر تغییرات Kp، Ki، Kd را بر پاسخ سیستم بنویسید.

د) چالش خلاقانه ★

۹ یک سیستم کنترل موقعیت برای بازوی رباتیک با PID طراحی کنید و پایداری آن را تحلیل کنید.
۱۰ یک کنترلر PID تطبیقی (Adaptive) پیشنهاد دهید که با تغییر بار، پارامترها را خودکار تنظیم کند.
